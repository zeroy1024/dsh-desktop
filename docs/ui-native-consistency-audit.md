- rewind 17 项测试、activity-group 13 项测试通过；rewind 类型检查通过。
- 全部插件构建、stage 和 macOS Electron 启动/重启检查通过；末次动作行 CSS 对齐后重新构建并 stage。
- 使用隔离 DSH_HOME 的真实页面：默认气泡计算样式 14px/22px；设置增大两档后 16px/24px，时间和分组标题为次级 14px，与原生思考行一致；深色截图人工复核，控制台无输出。

## 侧栏尺寸补充复核

此前仅核对 CSS 值，遗漏了新版 DOM 结构变化：设置入口由直接子按钮变为 wrapper 内按钮，旧 `> button` 规则失效，实测 300×42/r12/x10；普通行是 296×32/r8/x12。搜索结果又改成 button treeitem，被旧 div 限定漏掉。

已将行规则改为 role 选择器，设置仅定位 aria-haspopup=dialog 的触发器，同时重置其 wrapper 的额外宽度和负边距；不匹配同级连接状态动作。搜索结果改为单行布局保留工作区/摘要。实际页面（侧栏320px）确认新会话、项目、会话、设置及搜索结果均为296×32/r8/x12。本次只改客户端 desktop-frame CSS，未改上游。

### 审查页摘要条窄面板溢出（2026-09-05）

会话/工作区两种模式的摘要条原来强制单行，长分支名、统计数字和不可收缩按钮的总宽度会超出面板。改为统计/动作两个可换行的组，分支名限制宽度并省略（title 保留完整名称），动作组不足一行时自动换行，极窄面板允许按钮文字折行。保留原有字号与控件样式，不通过裁切隐藏操作。

验证：审查插件 37 个单测、类型检查、构建通过；使用实际 CSS 的独立 Chromium 布局样例，覆盖中英文、超长无空格分支名、六位增删统计及 240/320/480/640/900px 面板宽度，摘要条与按钮均无横向越界。此次几何验证是独立布局样例，不是完整 Electron 会话交互测试。

### 摘要条改为单行工具栏（替代上述换行方案）

根据反馈取消换行。统计信息占据弹性区域，长分支名省略并保留完整 title；右侧仅保留刷新与“审查选项”菜单两个固定尺寸按钮。菜单提供两种排序（标明当前项）和全部标记/取消已审操作，沿用原生 Menu 的 portal 浮层。两个改动源复用 SummaryActions。

验证：38 个审查单测（含菜单动作回归）、类型检查、构建通过。独立 Chromium 布局样例在 240–900px 的五档宽度下均保持 26px 单行，操作按钮完整可见且无横向溢出。
